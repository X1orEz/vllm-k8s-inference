# Развертывание vLLM на Kubernetes (CPU, Rootless, кэширование)

Справочное решение для запуска `Qwen/Qwen2.5-1.5B-Instruct` на фреймворке vLLM 
в среде Kubernetes (Minikube).

**Особенности:**
- Контейнер запускается от непривилегированного пользователя (rootless).
- Python-зависимости жестко зафиксированы.
- Кастомное логирование: промпты и ответы пользователей **не** выводятся в stdout.
- Модель кэшируется на `PersistentVolumeClaim` (PVC) через `initContainer` (идемпотентно).
- Секреты (токен HF и API-ключ) передаются через k8s `Secret`.
- Параметры vLLM управляются через `ConfigMap`.
- Kustomize для деплоя (Бонус 1) и отдельный легковесный init-образ (Бонус 2).
- Скрипт нагрузочного тестирования (Бонус 3).

## Требования
- Docker, Minikube, kubectl.
- Для CPU-сборки vLLM может потребоваться до 8 ГБ ОЗУ (рекомендуется добавить swap).
